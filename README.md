#### System Overview
UTCMS is an open-source content management system built on the UT Framework and its visual packages, capable of rapidly developing various types of applications, adhering to the Apache 2.0 and UT license.

#### Project Home
- https://github.com/usualtool
- https://gitee.com/usualtool

#### Characteristic
- Built on the UT Framework, it adopts the popular MVC modular development approach.
- It consists of two parts: the UT core framework and the visual development package.
- Support for quickly building various types of applications.
- Support common databases such as MySQL, SQLS, PgSQL, MongoDB, etc.

#### Requirement
- Web Server: Nginx / Apache / IIS
- PHP 7+（UT Framework 7+）
- Database: MySQL / MSSQL / PgSQL

#### Installation method 
- Download the installation package and unzip it.
- Run the application domain/IP for initial configuration.
- The initial super account/password is admin.
